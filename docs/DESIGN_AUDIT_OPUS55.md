## 2. 초기 진단 (우선순위별)

### P0 — 학습이나 조작을 방해

1. **Step 03 조작과 결과가 화면에서 분리됨.** “먼저 A와 B의 처리 조건을 고르세요”라고 안내하지만 선택 상자와 슬라이더는 3D 비교 그림 **아래**에 있다.
   1280×720 창에서 B 처리 조건 선택 상자는 B 3D 패널보다 767px 아래였고, B 누출 슬라이더를 움직이는 순간 B 패널 상단은 viewport 위 **−635px**였다(직접 측정).
   390px에서는 A 3D → B 3D → A 조절 → B 조절 → 결과 막대 순서라 B 조절과 B 그림의 거리가 1000px 이상.
   이 모듈의 핵심인 “조건을 바꾸면 막에서 무엇이 달라지는가”를 동시에 볼 수 없다.
2. **휴대폰에서 핵심 그림·표가 잘린 채 표시되고, 잘렸다는 표시가 없음.** 세포호흡/광합성 개요 그림(min-width 720px)은 왼쪽 1/3만 보인다.
   광합성의 비순환/순환 비교표는 390px에서 `Cyclic electron flow` 열 자체가 화면 밖이라 **비교가 불가능**하다. 요약표도 3열만 보인다.

### P1 — 학습 흐름과 정보 위계를 크게 떨어뜨림

3. **첫 화면에 그림보다 제목이 많음.** 탐색기 00 (1440×900): 영문 eyebrow → h1 → 리드 → `INVESTIGATION / 00` → h2 → 질문 → 문단 → 문맥 버튼 → 체크박스 상자 → 카드 머리말(질문을 다시 말함) 순서로, 3D 그림은 y≈750에서 시작해 **첫 화면에 거의 보이지 않는다.**
4. **탐색기 좌측 모듈 목록이 콘텐츠 폭을 잡아먹음.** 1024px에서 콘텐츠 폭이 약 760px로 줄어 Step 03의 A/B 3D가 각각 약 240px 폭이 된다. 768px에서도 사이드 목록이 유지되어 A/B가 세로로 쌓인다.
5. **Step 01 슬라이더와 그 결과가 떨어져 있음.** A/B 구획 그림(점 개수·방향) → 설명 → `직접 바꿔 보세요` 슬라이더 → 수치 순서. 첫 슬라이더를 화면 중앙에 두면 구획 그림은 위로 잘리고(−55px) 결과 수치는 화면 하단 끝. 모바일에서는 완전히 분리.
6. **같은 역할의 탭이 페이지마다 다른 모양.** 세포호흡 4칸 그리드 탭(옅은 배경), 광합성 작은 세그먼트, 탐색기 좌측 세로 목록, 기본/심화 버튼(위치가 heading 오른쪽 880px 지점에 떠 있음). 학습자가 “이것이 탭인지, 토글인지”를 매번 다시 읽어야 한다.
7. **‘+ 심화’가 무엇을 여는지 버튼만으로 알 수 없음.** 버튼 이름이 `+ 심화`뿐이고, heading 줄의 오른쪽 끝도 아닌 애매한 위치에 있다.
8. **작은 글자가 많음.** 3D 패널 상태 라벨 9px, 요약 dt 10px, 캡션 10–11px, 범례 11px, 표 12px, `quiet` 12px. 교실 프로젝터와 iPad에서 읽기 어렵다.
9a. **탐색기 ‘다음 단계 →’를 누르면 새 단계의 중간·끝에 도착.** 내장 브라우저(1280×720)에서 00 하단의 버튼을 누르자 01 제목이 viewport 위 −1087px에 있었다. 학습자는 새 단계의 질문을 보지 못하고 공식 접기 부분부터 보게 된다.
9. **3D 오버레이 라벨이 모바일에서 판독 불가.** 680×450 viewBox가 약 330px로 축소되어 `Complex I`, `NADH`, `FADH₂*`가 7–8px. 1440px에서도 탐색기 00 오버레이는 반대로 너무 커서(`막사이공간` ≈ 30px) 입자·막과 겹친다.

### P2 — 시각적 완성도·일관성

10. **AI landing page처럼 보이는 패턴**(3장 참조): 영문 대문자 eyebrow, 큰 카드 + 장식 그림 + `↗` 아이콘(내부 링크인데 외부 링크 표시), `READY TO EXPERIMENT?` CTA 띠, pill, 모든 것을 감싼 둥근 상자.
11. **상자 안의 상자.** 탐색기 00: 체크박스 상자, 3D 카드, takeaway 색 상자. 02: 상속 조건 색 상자, 그림 카드, 비교 색 상자, 결과 색 상자 — 한 화면에 상자 4개.
12. **수지(ledger) 띠가 지나치게 넓게 퍼짐.** `ATP 사용 2 … 피루브산 2`가 1128px 폭에 균등 분배되어 숫자와 이름의 짝이 눈에 들어오지 않는다.
13. **그림 속 라벨 겹침.** 세포호흡 개요의 `04 전자전달계` 노드를 H⁺ 화살표가 관통, 전자전달계 확대도에서 `H⁺` 화살표 라벨이 흩어진 H⁺ 기호와 겹쳐 `H⁺H⁺`, Calvin 그림에서 `Rubisco · 탄소 고정` 라벨을 CO₂ 화살표가 관통.
14. **광합성의 ‘두 시스템의 공통 원리’ 블록이 마지막 버튼 뒤에 있음.** 학습 확인/다음 버튼을 누르고 떠나면 보지 못한다.
15. **심화 해당과정 지도의 ‘전체’ 필터에서 모든 반응이 강조 상자로 칠해짐.** 강조가 강조 역할을 못하고 점선 상자만 10개 늘어난다.

### P3 — 미세 polish

16. 머리말의 `포털로 돌아가기 ↗`(같은 창에서 열리는데 외부 아이콘).
17. 각 페이지 h1이 41px로 형제 자료(22–24px)보다 과하게 크다.
18. 요약표 `td` 회색 글자(#5b6c5d) + 12px로 대비·크기 모두 약함.
19. 탐색기 00 ‘움직임 일시정지’ 버튼 11px.

## 4. 변경 원칙 (작업 후 작성)

1. **그림이 주인공, UI는 조연.** 각 화면의 첫 화면에 핵심 그림이 들어오도록 그림 앞의 heading·설명 층을 줄이고, 조작 도구는 그림 **옆이나 바로 위아래**에 둔다.
2. **원인과 결과를 한 화면에.** 슬라이더·선택 상자는 그것이 바꾸는 그림·수치와 같은 시야에 둔다(01: 그림·수치 | 슬라이더, 02: 그림/계산 | 판정, 03: 조건 선택 → 3D → 세부 슬라이더를 A·B 각 열에).
3. **HAFS Biology Lab 시각 언어로 통일.** 흰 배경, breadcrumb 머리말, 왼쪽 정렬 밑줄 탭, 작은 radius(6–8px), 얇은 선. 강조 색은 기존 녹색 하나.
4. **장식 층 제거, 정보는 보존.** 영문 대문자 eyebrow·pill·`↗`·CTA 띠·중첩 상자를 걷어내고, 그 자리를 한국어 짧은 라벨·선·여백으로 대신한다. 과학 문장은 지우지 않고 위치(본문 → 캡션/각주/접기)만 바꾼다.
5. **같은 역할 = 같은 모양.** 세포호흡 단계·광합성 모드·탐색기 단계가 모두 같은 밑줄 탭 문법을 쓴다. 토글은 버튼, 선택은 탭, 보기 설정은 체크박스.
6. **읽을 수 있는 크기.** 본문 16px, 보조 13–15px, 학습자에게 보이는 HTML 글자는 12px 미만을 쓰지 않는다. 조작 요소는 최소 40–44px 높이.

## 6. 유지한 부분과 이유

- **과학 내용·계산·상태 로직 전부**: `science.ts`, `respirationPathways.ts`, `content.ts`, `animationState.ts`, `EtcScene.ts`(3D 장면), 퀴즈 정답·해설, 저장 키 4개, page views 모듈, `vite.config.ts`/배포 설정은 손대지 않았다.
- **용어의 한·영 병기**(`Linear electron flow`, `ATP synthase`, `Thylakoid lumen`)와 SVG 안의 영문 구획 라벨: 수업 용어이므로 유지하고 자간·대문자 장식만 줄였다.
- **녹색 강조색, 갈색(H⁺)·파랑(e⁻)·녹색(ATP) 의미 색**: 그림 전체의 범례와 연결되어 있어 유지.
- **기본/심화 구조와 버튼 이름(`+ 심화`, `− 기본으로`)**: 기존 학습 흐름·키보드 동작·테스트 계약을 유지하고, 버튼 옆 설명 문구로 목적만 보강.
- **탐색기 단계 번호 00–05, 탭 번호 00–03**: 수업 중 교사가 “03번 단계”처럼 부르는 기준이므로 유지.
- **작은 장기 모식도(홈)**: 학습자가 두 주제를 시각적으로 구분하는 단서. 크기를 줄이고 판독 불가한 영문 캡션만 숨김(모바일에서는 생략).

## 8. 남은 UX 문제

1. 390px의 개요 그림(세포호흡·광합성)은 여전히 좌우 스크롤이 필요하다. 모바일 전용 세로 개요 그림을 따로 그리는 것이 근본 해결이다(과학 그림 재작성이 필요해 이번 범위에서 제외).
2. 768px(iPad 세로)에서 Step 03의 B 패널은 A 열 아래에 있다. 테스트 계약(1024px 미만에서는 세로 배치)을 유지했기 때문이며, B 조건을 바꾸는 순간에는 B 패널이 바로 위에 있으므로 조작–결과 거리는 확보된다.
3. 3D 개념 모형의 장면 자체(카메라·입자 크기)는 바꾸지 않았다. 390px에서 입자와 막 단백질은 작게 보인다.
4. 심화 해당과정·TCA 지도는 여전히 정보 밀도가 높다(이번에는 ‘전체’ 필터의 강조 상자만 제거).
5. Pretendard는 별도 로드하지 않는다(형제 자료와 동일). 설치되지 않은 Windows PC에서는 맑은 고딕으로 표시된다.
