## 00을 통합한 이유

축적 장소를 보여 준 다음 같은 막에서 경로를 다시 설명하던 두 화면을 합쳤다. 학생이 하나의 장면에서 전자의 운반체 간 전달, 기질 → 막사이공간 H⁺ 펌핑, 막사이공간 축적, ATP 합성효소를 통한 기질 귀환과 ATP 생성을 연결하도록 했다. 세 경로의 표시 전환은 강조·관찰용이며 과학 계산이나 반응 차단 조작이 아니다.

`ConceptMembrane`은 기존 `step04/EtcScene.ts`의 막·입자 이동·회전자·ATP pulse·렌더링 수명 관리와 `sceneLayout.ts`의 카메라 좌표를 재사용한다. `concept` 옵션으로 II의 구조와 전자 진입 가지를 생략하고, 별도의 한국어 SVG 라벨을 같은 투영에 겹친다. 기본 라벨은 전자전달계·H⁺ 펌핑·ATP 합성효소이다. I·III·IV, II 비펌프, Q·cyt c, 진입 차이는 접힌 심화 설명에 둔다.

## 01: 개념 → 조작 → 결과 → 식

농도 차와 전위 차를 두 카드로 먼저 설명한다. 구획 A/B의 pH와 각 성분이 선호하는 방향을 그림으로 나타내고, pH·전위 차·온도를 조절하면 두 기여와 합계가 함께 갱신된다. 두 성분이 서로 반대 방향으로 작용하는 경우에도 합계로 이동 방향을 결정한다.

수식은 하단의 닫힌 `details` 안에 있다. pH와 전위의 A/B, H⁺와 cycle 등의 첨자는 의미 있는 HTML `sub`/`sup`로 렌더링한다. 화면에 `pH_A`, `ψ_B`, `ΔG_H` 같은 코드 표기를 쓰지 않는다. 별도 수식 라이브러리나 새 의존성은 추가하지 않았다. 슬라이더 접근성 이름은 ‘A 구획 pH’, ‘B 구획 pH’, ‘전위 차 Δψ’로 읽힌다.

원래의 `science.ts`는 변경하지 않았다. Δψ는 도착 B 전위 − 출발 A 전위, 에너지는 A → B 이동 기준이다. 식에 표시한 2.303과 달리 계산은 기존의 `Math.LN10`을 유지한다. mV → V, °C → K, J → kJ 변환도 유지한다.

## 02: 왜 이 계산을 하는가

1. 01에서 설정한 조건과 H⁺ 1개당 이동 에너지를 이어받는다. 수치는 H⁺ 1몰 기준임을 함께 밝힌다.
2. 유효 H⁺/ATP 결합비 n을 곱해 ATP 1몰에 대응하는 H⁺ 이동 에너지를 구한다. 소수 결합비는 많은 ATP에 대한 평균이다.
3. H⁺가 제공할 수 있는 에너지의 크기와 양의 ATP 합성 요구량을 같은 눈금의 막대로 비교한다. 마지막에는 부호를 유지한 결합 자유에너지와 충분/부족/평형을 제시한다.

합계 계산은 기존 `coupledEnergy` 그대로다. H⁺ 이동이 오르막(양의 ΔG)인 경우 제공량을 양수로 뒤집어 그리지 않는다. 제공량 막대는 0이며, 이동 자체에 필요한 추가 비용을 명시하고 결합 결과에 더한다. 막대는 에너지 크기 비교이며 반응 속도나 ATP 개수 예측이 아니다. n과 ATP 비용은 단계 이동 후에도 유지된다. 기울기를 고치려면 명시적인 버튼으로 01에 돌아간다.

## 단순화와 실제 기작의 경계

- 구획 방향과 ATP 합성효소의 기질 쪽 촉매부 방향을 유지했다. 장면은 내막의 일부이며 실제 분자 크기·모양·농도비·시간·화학량론을 재현하지 않는다.
- 파란 점은 전자 전달을 표시한다. 자유 전자가 관을 따라 헤엄친다는 뜻이 아니다. 기본 장면은 NADH 쪽 진입 흐름을 대표로 보여 준다.
- 주황 점과 화살표는 H⁺ 막 횡단의 순방향을 요약한다. 복합체 III의 Q cycle이나 세부 프로톤 전달 경로는 생략했다. Complex II가 펌프라는 오해를 만들지 않도록 II를 기본 장면에서 제외하고 심화에서 비펌프임을 명시했다.
- 초록 ATP pulse와 회전은 합성 연결을 나타낸다. pulse 개수와 H⁺ 입자 수가 실제 H⁺/ATP 비를 뜻하지 않는다. ADP·무기 인산의 반응 전체와 역 ATPase 작동은 생략했다.
- 농도 점은 많고 적음만 표현한다. pH 차이에 따른 지수적인 실제 농도비를 점 개수로 나타내지 않는다.
- 음의 결합 자유에너지는 지정 방향의 열역학적 유리함을 뜻한다. 작동하는 효소와 기질이 필요하며 속도는 결정하지 않는다. 새 03의 상대 속도 모형은 새 01·02의 자유에너지와 별개다.
